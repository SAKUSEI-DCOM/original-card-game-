影絵アニメーション更新版（全12種類）

使い方：このフォルダの全ファイルを同じ階層構成でGitHub Pages等にアップロードしてください。
index.html = BOT対戦・ホーム
online.html = オンラインロビー
field.html = オンライン対戦画面
animated_silhouettes.js/.css = 12種類の影絵アニメーション本体
online_assets/ = オンライン試作エンジン・検証スクリプト

実装内容：指定色を反映した背景、シルエット、各カード固有の動作。怪異は8人の人影が順に文鳥の影に変化。
注意：SVG/CSSによる簡易ベクター影絵です。動画制作のような精細なフレームアニメーションではありません。
オンライン実機2台接続、Firebase権限・秘密情報保護、全カード効果の検証は未完了です。

今回の変更：必殺ファン●ションの影絵演出を「ロボット起動」から「ロボットの必殺技」に変更。
6秒周期：構え→右腕砲を照準→青白いエネルギーを充填→ビーム発射→衝撃波・閃光→余韻。シマエナガも登場。
カード効果、ガチャ排出率、ON/OFF設定は変更していません。

追加工程：animation_preview.html に12種類の演出プレビュー、再生/一時停止/速度変更を追加。怪異の人影→文鳥の変身を時間差で調整。

【今回の更新】animation_preview.htmlに再生位置シーク、1秒コマ送り、停止、速度変更、キーボード操作を追加。動きを止めたい環境では初期停止。影絵のキャラクター素材とカード効果は変更なし。

【オンライン同期改善】
・カード使用時の豪華演出を対戦ログの文字検索から、luxuryEvents（通し番号付き）へ変更。
・初回接続で過去の豪華演出を再生せず、新しい演出のみキュー再生。
・演出を閉じたときに次の演出を再生。
・BOTデモも同じイベント処理を使用。
